د تذکرې معلومات سکین Web App

فایلونه:
- index.html
- style.css
- script.js

د کارولو طریقه:
1) درې واړه فایلونه په یوه فولډر کې وساتئ.
2) index.html په براوزر کې پرانیزئ.
3) Camera permission ورکړئ، یا له Gallery څخه د تذکرې عکس وټاکئ.
4) "سکین پیل کړه" ووهئ.
5) راایستل شوي معلومات وګورئ او د اړتیا په صورت کې یې اصلاح کړئ.
6) هره خانه جلا کاپي کولی شئ.

محرمیت:
- د تذکرې عکس د دې اپ خپل سرور/ډیټابېس ته نه لېږل کېږي.
- OCR په براوزر کې اجرا کېږي.
- Tesseract.js او د ژبې فایلونه د CDN څخه ډاونلوډېږي؛ د تذکرې عکس نه پورته کېږي.
- دا نسخه د رسمي هویت تصدیق نه کوي او OCR ممکن غلط متن راوباسي.

مهم:
د Camera API عموماً HTTPS یا localhost ته اړتیا لري. که index.html په مستقیم ډول د file:// له لارې کیمره خلاصه نه کړي، فایلونه په HTTPS ویب‌سرور (لکه GitHub Pages) کې خپاره کړئ.
